Installation/Setup (UEFI Laptop)

This guide describes the installation/setup process for my current only system, MarshallJCM900. Future guides will be more generic/informative and give more in depth explanations for users who wish to follow this guide for their own system

Setting up the installation environment

Login as the user nixos. Set your keyboard layout if you are using one other than the default. Example for the DVORAK keyboard layout: 

$ sudo loadkeys dvorak

Set a password for the user nixos. Then set a root password. 

$ passwd

$ sudo passwd

Connect to a network. 

$ nmtui

Install over SSH (optional)

If you would like to connect via ssh from different machine, identify the IP address of this machine (the one you are installing to): 

$ ip a

Connect from the other machine using the IP address of the machine you are installing to. 

$ ssh nixos@<ip>

Preparing the disk

Become root user. 

$ su root

Identify drive on which you would like to install, then begin editing the drive in parted (replace nvme0n1 with the drive) 

# lsblk

# parted /dev/nvme0n1

In parted, create a GPT partition table. 

(parted) mklabel gpt

Create the ESP (boot) partition, and activate it: 

(parted) mkpart ESP fat32 1MiB 1025MiB

(parted) set 1 esp on

Create the swap partition. Use amount of RAM (or future amount of RAM) in machine instead of 32GiB. 

(parted) mkpart primary 1025MiB -32GiB

(parted) mkpart primary linux-swap -32GiB 100%

Quit parted. 

(parted) quit

Setting up encryption

Setup encryption on your root partition, and create a LUKS passphrase. Replace /dev/nvme0n1p2 with the name of the second (root) partition. This can be found by running lsblk. 

# cryptsetup luksFormat /dev/nvme0n1p2

Open the encrypted device. 

# cryptsetup open /dev/nvme0n1p2 cryptroot

Create/setup/mount filesystems

Create filesystem for ESP (boot) partition. 

# mkfs.fat -F 32 -n boot /dev/nvme0n1p1

Create a BTRFS filesystem for the root partition. 

# mkfs.btrfs -L nixos /dev/mapper/cryptroot

Initialize the swap partition and activate it. 

# mkswap -L swap /dev/nvme0n1p3

# swapon /dev/nvme0n1p3

Mount the root partition. 

# mount /dev/mapper/cryptroot /mnt

Create BTRFS subvolumes. 

# btrfs subvoume create /mnt/@root

# btrfs subvoume create /mnt/@home

# btrfs subvoume create /mnt/@nix

# btrfs subvoume create /mnt/@snapshots

Unmount the root partition and mount the root subvolume. 

# umount /mnt

# mount -o subvol=@root,compress=zstd /dev/mapper/cryptroot /mnt

Create subvolume directories. 

# mkdir -p /mnt/{home,nix,.snapshots,boot}

Mount the other subvolumes. 

# mount -o subvol=@home,compress=zstd /dev/mapper/cryptroot /mnt/home

# mount -o subvol=@nix,compress=zstd /dev/mapper/cryptroot /mnt/nix

# mount -o subvol=@snapshots,compress=zstd /dev/mapper/cryptroot /mnt/.snapshots

Mount the ESP (boot) partition. 

# mount /dev/nvme0n1p1 /mnt/boot

Creating the config files

Generate /etc/nixos/configuration.nix and /etc/nixos/hardware-configuration.nix. 

# nixos-generate-config --root /mnt

Identify the swap partition UUID. 

# lsblk -f

Open /mnt/etc/nixos/configuration.nix in a text editor 

# vim /mnt/etc/nixos/configuration.nix

Add these lines (replace 3127cd0b-acec-4fc1-a1f7-40bd981933e0 with swap partition UUID) inside the main { ... } block (enter input mode by pressing i): 

# During boot, check this swap partition for a hibernation image and resume from it if present.
boot.resumeDevice = "/dev/disk/by-uuid/3127cd0b-acec-4fc1-a1f7-40bd981933e0";

Write and quit by pressing Esc, w, q.

Installing

Verify mount. 

# findmnt -R /mnt

Install. 

# nixos-install

If successful, reboot. 

# reboot

Boot into installed system and create a user, and update

Upon startup, enter encryption password. You should enter into a login manager. Open a TTY by pressing Ctrl + Alt + F2. Login as root and create a user password. 

# passwd <user>

Update system. 

# sudo nixos-rebuild switch

Create user folders

# mkdir -p \
~/src/experiments/ \
~/src/external/ \
~/src/projects/henrycrusher \
~/Desktop \
~/Documents \
~/Downloads \
~/Music \
~/Pictures \
~/Videos \
~/Public \
~/Templates \
~/.local/share/backgrounds

Set up Git

Login as the user. Press Ctrl + d to logout of root. Set your identity. Replace YourName and you@example.com with your desired name and email. 

$ git config --global user.name "YourName"

$ git config --global user.email "you@example.com"

Create an SSH key. 

$ ssh-keygen -t ed25519 -C "you@example.com"

$ eval "$(ssh-agent -s)"

$ ssh-add ~/.ssh/id_ed25519

Copy your public key. 

$ cat ~/.ssh/id_ed25519

Go to https://github.com/settings/ssh/new. Title the key the name of your computer. Paste in the key. Create another, but make it a signing key. Then, test your connection. 

$ ssh -T git@github.com

From now on clone with 

$ git clone git@github.com:user/repo.git

not HTTPS. Set main as default branch. 

$ git config --global init.defaultBranch main

Tell Git to use SSH signing. 

$ git config --global gpg.format ssh

Point Git at your SSH key. 

$ git config --global user.signingkey ~/.ssh/id_ed25519

Enable signing by default. 

$ git config --global commit.gpgsign true

Set an editor. Replace vis with your perfered installed editor. 

$ git config --global core.editor "vis"

To edit my repo, clone it. 

$ cd ~/src/projects/henrycrusher/

$ git clone git@github.com:Shulginer/HenryOS.git
